# 🧠 MindCraft: AI Chat Mod

*A Minecraft Fabric mod that brings intelligent conversation right into your world.*

---

## ✨ Overview

**MindCraft: AI Chat Mod** adds an in-game artificial intelligence that you can talk to directly through chat.
Ask questions, get advice, or just chat with your digital companion — all without leaving Minecraft.

---

## ⚙️ Features

* 💬 **Chat with AI** — communicate naturally using in-game commands.
* 🤖 **Smart responses** powered by modern language models.
* 🔧 **Simple setup** — just drop the `.jar` into your `mods` folder.
* 🧩 **Lightweight** — built on the Fabric API with minimal dependencies.

---

## 🪄 Commands

| Command          | Description                                       |
| ---------------- | ------------------------------------------------- |
| `/gpt <message>` | Send a message to the AI and get a reply in chat. |
| `/chat`          | Opens a persistent conversation mode.             |

*(You can customize or expand commands in `gptmode/Commands/`.)*

---

## 🚀 Installation

1. Make sure you have **Minecraft Fabric Loader** installed.
2. Download the latest release of `mindcraft-ai-chat.jar`.
3. Move the file into your Minecraft `mods` folder:

   ```
   .minecraft/mods/
   ```
4. Launch Minecraft — the mod will load automatically!

---

## 🧩 Developer Notes

This mod uses an internal API handler (`api/chatGPT.java`) for AI communication.
You can modify API endpoints or keys in the configuration section before building.
